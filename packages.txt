# The ct-pkg repositories known to `ct-pkg/index`, one `name url` pair per line.
# The first column is the repository name; the package name inside `ct.pkg` may
# differ (the `rill-dsl` repository publishes the `rill` package).
#
# `tools/refresh-index.sh` resolves each repository's `v*` tags (all of them
# with --all-tags), clones the repository once and lets `tools/gen-index.sh`
# write one six-field line per version. A comment line or a blank line is
# skipped. Versions and publishers are not listed here: the remote tag and the
# package's own `ct.pkg` decide. `publisher` must be the same for every tag of
# one package; the newest tag defines it.
#
# Repositories without `publisher` / `ns-root` in their tagged `ct.pkg` cannot
# be regenerated yet. Their existing index rows are kept by
# `refresh-index.sh --only`; refresh them here once they publish the identity.
