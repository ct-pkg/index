## 决定

1. 批准 `draft-index-push-parity` 定稿为 `v0-PH-2`。
2. 回读失败时**不自动重试、不 force**：报错并人工重跑。自动重试会在并发窗口里制造

## 理由

- 实测 `package.sh` 的 `merge-base --is-ancestor` 命中 0 次，`ls-remote` 的 2 次都在
  `wait_for_tag`，索引推送路径既无快进断言也无回读。
- 主发布路径（`publish` / `release`）走 `publish_index`，而夜间 bot 会并发推进
  `main`，非快进正是最容易在该窗口发生的场景。
- `--force` 命中 0 次，禁 force 现状已满足，本 phase 只补缺失的两段。
