## 决定

1. 批准 `draft-gate-zero-input` 定稿为 `v0-PH-1`，并要求在 v1 发布前完成。
2. 明确 `CT_PKG_ROOT` 的语义：**未设置或为空时按默认工作区根解析**（`tools/../..`），
   这不算错误；只有当解析后的根下找不到任何 `*/ct.pkg` 时才失败。

## 理由

- 现状实测：空根下 `check-char-host.sh` 打印 `ok: 0 methods on 0 hosts` 并 rc=0，
  是真实的假绿；`check-layout.sh` 因 `set -u` 下空数组展开报 `packages[@]: unbound
  variable`，rc=1 但信息是 shell 内部错误，不是可诊断的门禁失败。
- 用户要求在 v1 发布前修复，优先级高于其余两份草案。
- 草案原范围未区分“环境变量缺省”与“扫描集为空”，本条一并写清，避免把默认行为
  误判成错误。

## 影响

- 本仓第二个正式 phase，`v0-PH-1`，`version-minor: 1`，收口版本 `v0.1.0`。
- 账本追加一行；`session-map.md` 增加一行。
